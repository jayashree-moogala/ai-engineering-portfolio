# Project 01 – AI Chat Service

## Overview

The AI Chat Service is the first project in my AI Engineering Portfolio. It provides a RESTful API that accepts natural language questions and generates AI-powered responses using the OpenAI Responses API.

The primary goal of this project is to establish the foundation for building AI-powered backend services while introducing the core technologies used throughout the remainder of the portfolio.

This project emphasizes clean application structure, API design, secure configuration management, and integration with a commercial Large Language Model (LLM).

---

# Objectives

The objectives of this project are to:

* Build a REST API using FastAPI
* Integrate with the OpenAI Responses API
* Securely manage API keys using environment variables
* Design request and response models with Pydantic
* Learn the architecture of AI-powered backend services
* Establish reusable project patterns for future AI applications

---

# Features

* REST API built with FastAPI
* OpenAI Responses API integration
* JSON request and response format
* Interactive Swagger API documentation
* Environment-based configuration
* Modular application structure
* Input validation using Pydantic

# Installation

## 1. Clone the repository

```powershell
git clone https://github.com/jayashree-moogala/ai-engineering-portfolio.git
```

## 2. Navigate to the project

```powershell
cd projects\01-ai-chat-service
```

## 3. Create a Python virtual environment

```powershell
python -m venv .venv
```

## 4. Activate the virtual environment

```powershell
.\.venv\Scripts\Activate.ps1
```

Your PowerShell prompt should now look similar to:

```text
(.venv) PS C:\source\ai-engineering-portfolio\projects\01-ai-chat-service>
```

## 5. Install project dependencies

```powershell
pip install -r requirements.txt
```

# Configuration

Create a file named `.env` in the project root.

```text
OPENAI_API_KEY=your_openai_api_key_here
```

> **Important:** Never commit your `.env` file to GitHub. It is ignored by the project's `.gitignore`.

# Example API Request

### Endpoint

```http
POST /ask
```

### Request Body

```json
{
  "question": "What is Prompt Engineering?"
}
```

### Example using PowerShell

```powershell
Invoke-RestMethod `
    -Uri "http://127.0.0.1:8000/ask" `
    -Method POST `
    -ContentType "application/json" `
    -Body '{"question":"What is Prompt Engineering?"}'
```

### Expected Response

```json
{
  "question": "What is Prompt Engineering?",
  "answer": "Prompt engineering is the practice of designing and refining prompts to improve the quality, accuracy, and usefulness of responses generated by large language models."
}
```
