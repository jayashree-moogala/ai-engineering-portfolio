# AI Engineering Portfolio

> A hands-on portfolio demonstrating modern AI engineering concepts, production-ready software architecture, and practical applications of Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), AI Agents, and Model Context Protocol (MCP).

---

## Overview

Welcome to my AI Engineering Portfolio.

This repository documents my journey from traditional software engineering into modern AI engineering through a series of progressively more advanced projects.

Rather than focusing solely on prompting Large Language Models, this portfolio emphasizes **software engineering principles applied to AI systems**, including modular architecture, API design, testing, observability, automation, and production-ready development practices.

Each project builds upon the previous one and demonstrates a specific capability used in real-world AI applications.
